Precision vs Recall · qué mide cada una

MLA-C01 · tarjeta de estudio · Precision = TP / (TP + FP)

Pregunta: ¿qué mide la Precision (a diferencia del Recall)?

Respuesta: D — la proporción de positivos correctos entre todos los que el modelo predijo como positivos = TP / (TP + FP).

La idea en una frase: Precision y Recall comparten el mismo numerador (TP, los aciertos positivos) pero dividen entre conjuntos distintos.   Precision = "de lo que MARQUÉ positivo, cuánto acerté".   Recall = "de lo que ERA positivo, cuánto atrapé".
1) Precision = de lo que MARQUÉ positivo, cuánto acerté

Precision mira solo la columna de lo que el modelo predijo Passed (TP + FP). De esa columna, ¿qué fracción era realmente correcta? = TP / (TP + FP). Se equivoca cuando hay muchos falsos positivos (FP): cosas que marcó Passed pero no lo eran. Respuesta D = esta.

2) Recall = de lo que ERA positivo, cuánto atrapé

Recall mira solo la fila de lo que realmente era Passed (TP + FN). De esa fila, ¿qué fracción logró detectar el modelo? = TP / (TP + FN). Se equivoca cuando hay muchos falsos negativos (FN): Passed reales que se le escaparon. Es la opción A del examen (sensibilidad), no Precision.

3) La diferencia clave: mismo numerador, distinto conjunto

Las dos usan el mismo numerador (TP, los aciertos positivos), pero dividen entre conjuntos distintos: Precision divide entre 'lo que yo predije positivo' (TP+FP); Recall divide entre 'lo que realmente era positivo' (TP+FN). Truco: Precision se castiga por FP; Recall se castiga por FN.

4) Cuándo importa cada una y qué son los distractores

Precision alta importa cuando un falso positivo es costoso (ej. un frenado innecesario en conducción autónoma). Recall alto importa cuando perder un positivo real es grave (fraude, diagnóstico). Los distractores son OTRAS métricas: A = Recall/sensibilidad; B = Accuracy (aciertos sobre el total); C = False Positive Rate (negativos marcados como positivos). Solo D describe la Precision.

Regla para el examen: Precision = TP/(TP+FP), la castigan los falsos positivos (importa si un FP es caro).   Recall = TP/(TP+FN), lo castigan los falsos negativos (importa si perder un positivo es grave).   F1 = balance de ambas.   Accuracy = aciertos/total; FPR = negativos marcados como positivos.

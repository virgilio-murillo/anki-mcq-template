Pregunta: se quiere visualizar la relación entre DOS variables concretas (una en X, otra en Y), apreciar si suben/bajan juntas e identificar outliers. ¿Qué técnica usar?

Respuesta: A — Scatter plot. Es la única de las cuatro que grafica pares (x, y) individuales, revela la correlación y su fuerza, y deja ver los puntos atípicos.

A Scatter plot (gráfico de dispersión) ✓ CORRECTA

Coloca cada par (x, y) como un punto en el plano. De un vistazo revela: (1) si las dos variables suben/bajan juntas (correlación), (2) la fuerza de esa relación (qué tan apretada está la nube) y (3) los outliers (puntos que se escapan del patrón). Es la única que responde exactamente a lo pedido: relación entre DOS variables + outliers.

C Histograma ✗ distractor

Muestra la distribución de frecuencias de UNA sola variable: divide su rango en intervalos (bins) y cuenta cuántos valores caen en cada uno. Sirve para ver forma, sesgo y rango de una variable, pero no relaciona dos variables ni muestra outliers de pares.

D Análisis de multicolinealidad ✗ distractor

Cuantifica la redundancia lineal entre VARIAS variables predictoras a la vez (típicamente una matriz de correlación o el VIF). Dice si hay features que aportan lo mismo, pero es un resumen numérico global: no visualiza un par concreto ni marca puntos atípicos individuales.

B Gráfico de valores Shapley ✗ distractor

Atribuye cuánto contribuye cada feature a UNA predicción del modelo (explicabilidad, vía SageMaker Clarify). Responde 'por qué el modelo predijo esto', no 'cómo se relacionan dos variables entre sí' ni dónde están los outliers.

Regla mnemónica para el examen: "relación entre DOS variables + outliers" → scatter plot. "Distribución de UNA variable" → histograma. "Redundancia entre muchas variables" → multicolinealidad. "Por qué el modelo predijo X" → valores Shapley (Clarify).

# clarity/ — canonical toolchain pointer

There is ONE clarity-validation toolchain. It lives at the **root** of `kiro-test/`,
NOT inside this `clarity/` directory:

| Phase | Script (canonical, root) | Writes |
|---|---|---|
| A — build blind batches | `kiro-test/clarity_make_batches.py` | `clarity/blind_batches/batch_NN.json` (stem+options only, NO key) + `clarity/answer_key.json` |
| A' — render prompts | `kiro-test/clarity_make_blind.py` | `clarity/blind_prompts/` |
| C — consolidate verdicts | `kiro-test/clarity_consolidate.py` | `clarity/clarity_verdicts.json` + `clarity/clarity_report.md` |

Thresholds live in `clarity_consolidate.py`: `AGREE_MIN=0.75`, `CONSENSUS_MIN=0.75`,
`FLAG_MAX=0.33`, `RUBRIC_MIN_OK=9`. Consensus is key-INDEPENDENT (`modal_n/n`); a card
that matches the key can still be NEEDS_IMPROVEMENT/P0 on flags alone.

## Deleted orphan toolchain (do not recreate)
An unrelated `clarity_consensus.py` / `_perm.py` / `test_consensus.py` /
`clarity_make_batches.py` (the `blind_batches_multi/cand_*` variant) once coexisted here.
It was NEVER executed in the pair-2 investigation (0 hits in `investigator.log` for its
unique strings and its `gold.json` dependency) and had a different, key-DEPENDENT P0
branch (`not matches_gold`). It was removed to stop confusion. If you need multi-candidate
permutation, add it INSIDE the root `clarity_make_batches.py`, not as a parallel file.

## Self-test (committed, log-independent)
`clarity/selftest/run_selftest.py` loads `verdict_for()` from the root consolidator by path
and asserts, with committed fixtures:
- INV-1: agreement=1.0 card is still NEEDS/P0 purely on `flag_rate` (claim: "passing the key
  does not save an ambiguous card")
- INV-2: 3-way split -> NEEDS
- control clean card -> CLEAR

Run: `../../../.venv/bin/python kiro-test/clarity/selftest/run_selftest.py`

## Derived vs durable artifacts
`blind_batches/`, `blind_prompts/`, and live candidate passes are DERIVED — regenerated by
one command from `qa_cards_paired.json`. Their absence is not data loss. Only the scripts,
`answer_key.json`, and `selftest/` fixtures are durable.
